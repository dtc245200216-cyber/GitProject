# Thực hành: Sử dụng CSS

Bài thực hành CodeGym sử dụng Internal CSS trong file `index.html`.

Các nội dung:
- `h1`: chữ màu xanh, font Tahoma, cỡ 200%.
- `p`: chữ màu đỏ, font Arial, cỡ 120%, viền xám 1px và padding 10px.
- `#element1`: đổi riêng màu chữ đoạn văn có `id="element1"` sang xanh.

Mở file [index.html](index.html) bằng trình duyệt để xem giao diện.
