Bài tập CSS Box Model

Thẻ 1: Content Box

Sử dụng box-sizing: content-box. Tổng kích thước lớn hơn giá trị width và height đã khai báo.

Thẻ 2: Border Box

Sử dụng box-sizing: border-box. Padding và border được tính trong kích thước khai báo.

Thẻ 3: Border Box

Thẻ màu đỏ cũng sử dụng box-sizing: border-box với cùng kích thước thẻ 2.
