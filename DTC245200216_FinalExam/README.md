# Product Manager - JSP Servlet Final Exam
Java 11, Tomcat 9, Maven, MySQL 8, JSP/JSTL and JDBC.
Run database.sql with MySQL, configure DB_URL/DB_USER/DB_PASSWORD if needed, run mvn clean package, deploy target/product-manager.war to Tomcat 9 webapps, open http://localhost:8080/product-manager/.
Features: list products, add, edit, delete with confirmation. Source not yet tested on an actual MySQL and Tomcat environment.
