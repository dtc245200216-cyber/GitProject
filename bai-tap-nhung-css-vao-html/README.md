# Bài tập: Nhúng CSS vào trang HTML

Ba cách thay đổi màu tiêu đề sang xanh lá và đoạn văn sang xanh dương:

1. [Phần 1 – Inline CSS](inline.html): dùng thuộc tính `style` trực tiếp.
2. [Phần 2 – Internal CSS](internal.html): dùng cặp thẻ `<style>` trong `<head>`.
3. [Phần 3 – External CSS](external.html): dùng thẻ `<link>` trỏ đến [style.css](style.css).

Mở [index.html](index.html) để xem danh sách ba ví dụ.
